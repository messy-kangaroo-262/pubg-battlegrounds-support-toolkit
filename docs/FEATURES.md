# PUBG Battlegrounds Support Toolkit — feature reference

PUBG Battlegrounds Support Toolkit groups support notes, session records, and configuration history in a single workspace. Each section keeps its controls and related settings together.

| Section | Description |
|---|---|
| Support notes | A dedicated section for support notes and the configuration details associated with that area. |
| Session records | Session and activity information grouped by the task or context it belongs to. |
| Configuration history | A dedicated section for configuration history and the configuration details associated with that area. |

The project page follows the same section structure.
